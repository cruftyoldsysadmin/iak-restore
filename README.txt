İSTANBUL AVRUPA KOROSU — OFFLINE SITE ARCHIVE
=============================================

Open index.html in any browser. No internet connection is needed.

WHAT THIS IS
  A working offline copy of www.istanbulavrupakorosu.org, rebuilt from two
  separate sources after Weebly discontinued service in Turkey.

  Pages (46 files)
      Source: the Internet Archive (web.archive.org).
      Captures range from Apr 20, 2014 to May 23, 2024.
      Every Internet Archive replay URL has been rewritten to a local path.
      Pages are therefore a mix of capture dates, not a single snapshot.

  Media (592 files)
      Source: downloaded directly from Weebly's servers, not the Archive.
      These are the original full-quality files, not archived copies.
      Weebly stored three copies of most files under decorated names
      (name, _name, name_1). Duplicates were removed by content hash;
      577 distinct files remain. See ../webnode/media-manifest.json
      for every file's hash and the alternate names it was stored under.

  Styling (14 files in assets/)
      main_style.css is the real site theme, taken from Weebly's own editor
      API rather than the Archive. The Archive's copies of main_style.css and
      templateArtifacts.js are corrupt at every capture — they return an
      error page instead of the file — so the Weebly original was used.

KNOWN GAPS
  Some images and files are referenced by the pages but no longer exist.
  They were deleted from Weebly years before the shutdown, so neither Weebly
  nor the Archive holds them. Those references are deliberately left in place
  pointing at media/ so the original filename stays visible in the page source
  as a record of what was there. No placeholder graphics were substituted.
  See ../missing-media.json for the full list.

  Form submission data is not here and does not exist anywhere. Weebly's
  export replaced every submitted answer with a type placeholder ("@." for an
  email, "weebly/uploads" for an attachment). 1,666 membership applications
  were lost this way. The only surviving trace is ../applicant-emails.csv,
  877 addresses that Weebly Promote had copied into a mailing group. Those
  addresses carry no names and never opted in to marketing.

  index.html is the March 2016 capture, the most recent one of the home page.
  index-2014.html is the April 2014 capture, kept for reference.

FORM BEHAVIOUR
  The contact and membership forms are visible but inert. They posted to
  Weebly's servers, which no longer accept them, so their action was set
  to "#" rather than left pointing at a dead endpoint.
